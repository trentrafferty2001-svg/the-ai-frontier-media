# The Ai Frontier: media

Finished videos (1080x1920, with music) for The Ai Frontier on Instagram, TikTok and YouTube.
They are hosted here so Buffer can fetch them by public link when a post is scheduled.

Link format: `https://raw.githubusercontent.com/trentrafferty2001-svg/the-ai-frontier-media/videos/videos/<name>.mp4`

Source projects (scripts, scenes, audio) live in the private `video-studio` repository.
